Every small game is a step forward in learning game development. Following the 20 Games Challenge, I'm building from simple classics to more complex experiences.

As a web developer venturing into game development, I'm following [The 20 Games Challenge](https://20_games_challenge.gitlab.io/) methodology - starting small with games like Pong or Flappy Bird and gradually working up to more complex projects. This approach helps avoid "tutorial hell" by encouraging direct experimentation with Godot engine's documentation.

This section documents each game in my journey, showing both the successes and the learning experiences along the way. While the code comes naturally from my web development background, I'm also learning:

- Digital art and animation
- Sound design and music
- Game narrative and storytelling
